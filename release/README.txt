Analog Movement for Minecraft Dungeons (v1.17.0.0, Steam)
==========================================================

Makes the hero's speed follow how far you tilt the left stick: half tilt
means half speed. At low speed the game's own walk animation plays and
blends into the run as you tilt further, with the step rate matched to
your speed so the feet don't slide.

REQUIREMENTS
- Dungeons Blueprint Loader 1.0 (Blueprint-Loader.pak) in the same ~mods folder.

INSTALL
1. Copy AnalogMove.pak into:
   <Steam>\steamapps\common\MinecraftDungeons\Dungeons\Content\Paks\~mods\
2. Start the game.

CONTROLS
- Left stick    Tilt to set your speed
- F8            Show/hide a debug readout (hidden by default)

Mouse click-to-move is unchanged and still moves at full speed.
Works together with the Third-Person Camera mod.

UNINSTALL
Delete AnalogMove.pak from ~mods. There is no in-game toggle.
